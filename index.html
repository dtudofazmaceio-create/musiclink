Uso da cota (hoje)

O YouTube libera 10.000 unidades por dia gratuitamente. Renova por volta das 4h–5h (horário de Brasília).

  • Cada música buscada: 100 unidades (≈ 100 músicas/dia). Buscas repetidas usam o cache e não gastam nada.
  • Criar uma playlist: 50 + 50 por música adicionada.

O contador é uma estimativa deste aparelho. O valor oficial fica no Google Cloud Console → APIs → Cotas.

Como obter as chaves (uma vez só, ~10 minutos)

  1. Acesse console.cloud.google.com e crie um projeto (ex.: “MusicLink”).
  2. Em APIs e serviços → Biblioteca, procure YouTube Data API v3 e clique em Ativar.
  3. Em Credenciais → Criar credenciais → Chave de API. Copie e cole no campo API Key acima. (Recomendado: restrinja a chave à YouTube Data API v3.)
  4. Em Tela de permissão OAuth (Google Auth Platform): tipo Externo, preencha nome e e-mail, e em Público-alvo → Usuários de teste adicione o e-mail do Google dono do seu canal.
  5. Em Credenciais → Criar credenciais → ID do cliente OAuth, tipo Aplicativo da Web. Em Origens JavaScript autorizadas adicione o endereço mostrado no quadro amarelo acima (ex.: https://seuusuario.github.io). Copie o ID do cliente e cole no campo acima.
  6. Clique em Salvar e depois em Conectar canal. Na tela do Google, escolha a conta/canal e autorize.
O login do Google não funciona abrindo o arquivo direto do computador (file://). Hospede o HTML em um endereço https (GitHub Pages, Netlify, Vercel, seu site) ou rode localmente com http://localhost. A busca de links funciona em qualquer endereço http/https.

Dados e backup

Tudo fica salvo no navegador deste aparelho. Faça backup para levar as listas para outro celular/computador.
